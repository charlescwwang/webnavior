# 周氏蝦捲點餐示範目錄研究

研究日期：2026-08-31

> 本筆記僅用於 AIRI WebMCP 點餐示範的虛構菜單素材；不是周氏蝦捲
> 的即時店內菜單、價格或供應承諾。品名與品類取自官方網站，實際售價、
> 份量、是否販售與過敏原資訊必須由餐廳/POS 的正式資料覆寫。

與「肉燥擔仔麵」僅於店內販售；其餘條目雖也可能有宅配版本，仍可作為菜色
靈感，但不可據此推論現場供應狀態。

## 讓示範像真實餐飲內容的目錄形狀

建議先建立 9 個官方同名品項，再加入少量**清楚標示為模擬**的組合品：
「蝦捲＋擔仔麵套餐」、「海鮮派＋魚羹套餐」及「肉燥飯」。這樣能讓
`menu_get` 回傳多個可比較類別（炸物、主食、湯品、甜點），也能練習單品、
套餐、選項與加購的 WebMCP 流程，同時不把虛構內容誤當成餐廳正式菜單。

適合的選項建模：

- `杏仁豆腐`：口味（杏仁／紅豆），必選一項。
- 炸物與肉粽：數量與是否切分／分享，僅在 UI 需要時提供；官方來源沒有列出
  此選項，應視為模擬互動。
- 湯品、擔仔麵：數量；不要臆造辣度、麵條或客製配料等官方沒有證實的選項。

## 價格與資料邊界

官方餐飲介紹描述國宴風味餐為預約制、每桌十人、依每桌價位計費，並非可直接
套用到單人 kiosk 的即食價目表。
[官方國宴風味餐頁](https://www.chous.com.tw/chous/resteaurant.html)

官方冷凍購物網則有包裝商品價格，例如高麗菜水餃 300 元、韭菜水餃 300 元、
南部花生肉粽（10 入）600 元、豆皮鮮蝦捲 225 元、古早味肉燥 150 元與極品
冷凍蝦捲 380 元。這些是冷凍宅配包裝價格，不是店內單人餐價格，故示範資料
不可把它們當作現場售價。
[官方冷凍商品列表](https://www.chous.com.tw/shoppingcool/m_mall_list.php?ps_ctid=01000000)

實作時應將 `isSimulated: true`（或等效 catalog provenance）與價格的資料來源
保留在菜單資料中；WebMCP 回傳的名稱、價格與可用選項只讀取該受控 catalog，
避免 agent 依產品介紹或網路搜尋自行補齊品項與價格。
